# Bruno AC Estimating

A professional HVAC estimating and job-costing PWA built for Bruno AC Services LLC.

Live app: https://kot0070.github.io/bruno-ac-pwa/

## Included in this repository

- Offline-capable estimating PWA
- HVAC Code & BOM Calculator
- Catalog / Job Materials workflow
- Quote and T&M invoice workflows
- Financial integrity / job profitability tooling
- Texas ACR customer-document support

See the app UI for the current production workflow and embedded reference notes.
